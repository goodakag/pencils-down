# Pencils Down

A realistic, first-person test-taking simulator. Load a past or sample test as a PDF, sit at a desk in a quiet morning classroom, and take it under real exam conditions: the bell, the wall clock, the sound of everyone else writing. When time is up, hand it in and save a PDF with your answers.

## Build from source

1. Install [Godot 4.7.2](https://godotengine.org/download).
2. Open `project.godot` in the Godot editor.
